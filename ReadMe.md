# hanan.in: Portfolio Website

Portfolio site of Muhammed Hanan, a freelance web developer building websites
for businesses in the UAE, US and UK.

Live site: https://hanan.in

## About
A hand-coded, single-page portfolio with interactive visuals:
- 3D hand scene (Three.js)
- Interactive globe
- Animated hero dot field
- Fonts and assets self-hosted, deployed on Netlify

## Tech
HTML, CSS, JavaScript, Three.js, Netlify

## Project structure
- `index.html`, `style.css`, `main.js`: main page
- `globe.js`, `globe-data.js`, `hand-scene.js`, `hero-dots.js`: interactive scenes
- `hand-lab.html`: 3D hand experiments
- `assets/`: fonts, images, 3D model
- `netlify.toml`: deployment config

## Built with
Developed with AI-assisted workflows using Claude Code.
